# 📰 Akçaabat Haber

Akçaabat ve Trabzon'dan güncel haberleri, gelişmeleri ve yerel içerikleri okuyuculara ulaştırmayı amaçlayan modern bir haber platformu.

## 🌐 Web Sitesi

**Akçaabat Haber**

https://akcaabathaber.com.tr

## 🚀 Proje Özellikleri

- Modern ve profesyonel haber tasarımı
- Mobil uyumlu responsive yapı
- Ana sayfa haber akışı
- Haber detay sayfaları
- Haber kategorileri
- Son dakika haberleri
- Çok okunan haberler
- Haber arama sistemi
- Yönetim paneli
- Haber ekleme ve düzenleme
- Taslak haber sistemi
- Yorum yönetimi
- Site ayarları
- SEO altyapısı
- Sitemap desteği
- Robots.txt desteği
- 404 hata sayfası
- PWA altyapısı
- Service Worker desteği
- GitHub Pages uyumluluğu
